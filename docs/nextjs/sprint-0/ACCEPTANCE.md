## Exit criteria

- Every one of the 89 route contracts migrated or given an explicitly verified compatible route; no silently dropped model/feature. Framework docs endpoints need no replacement business UI, but cannot masquerade as implemented APIs.
- All legacy expectations reproduced in TypeScript tests or explicitly reviewed changed behavior. Zero unresolved critical/high regressions; record each tolerated behavior change and owner agreement.
- Vitest unit + real PostgreSQL integration/races + Playwright + standalone Docker build/preview pass against the **same source digest**. Skips on production-critical cases fail the release gate.
- Full financial reconciliation compares original charges, adjustments, movements, net/outstanding/credit, dues, expenses and historical snapshot hashes per club/session/payer. Empty live tables do not waive rich-fixture tests.
- No production mutation tests. Run realistic writes on isolated local/preview data; production checks are GET/read-only until deliberate cutover activation. No automated DNS/DDL/destructive restore.
- Record commands, runtime versions, durations, failures, hashes and exact deployment/image IDs. Screenshot alone or a 200 login page does not demonstrate parity.
